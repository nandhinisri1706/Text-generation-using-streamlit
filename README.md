# AI Text Generator

A simple AI-powered text generation web application built using **Python, Streamlit, and Hugging Face Transformers**. The application provides a chat-style interface where users can enter a sentence or prompt and generate a continuation using the **EleutherAI GPT-Neo 125M** model.

## Features

* Chat-style text generation interface
* AI-powered text completion
* Uses GPT-Neo 125M from Hugging Face
* Adjustable maximum token generation
* Adjustable temperature
* Maintains chat history during the session
* Clear Chat option
* Simple and user-friendly Streamlit interface
* No API key required

## Technologies Used

* **Python**
* **Streamlit**
* **Hugging Face Transformers**
* **PyTorch**
* **GPT-Neo 125M**

Make sure Python is installed on your system.

Install the required libraries:

```bash
pip install streamlit transformers torch
```

## How to Run

### 1. Clone or download the project

Open the project folder in VS Code.

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

For Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install streamlit transformers torch
```

### 5. Run the application

```bash
python -m streamlit run app.py
```

The application will open in the browser.

## How It Works

The application follows this workflow:

```text
User enters a prompt
        ↓
Streamlit receives the input
        ↓
GPT-Neo 125M processes the prompt
        ↓
AI generates continuation text
        ↓
Generated text is displayed
        ↓
Conversation is stored in session state
```

### Maximum New Tokens

Controls the maximum amount of new text generated by the model.

```text
20  → Short text
50  → Medium text
150 → Longer text
```

### Temperature

Controls the randomness of the generated text.

```text
Low temperature  → More predictable
Medium temperature → Balanced
High temperature → More creative/random
```

## Model

This project uses:

```text
EleutherAI/gpt-neo-125M
```

The model is loaded using the Hugging Face Transformers `pipeline()` API.
